# `@relvo-labs/agent-runtime`

Provider-neutral composition root with mutation-isolated in-memory storage, scoped command idempotency, retained provider effects after transient persistence failure, retryable cleanup-aware shutdown, exactly-once terminal settlement, fail-closed lifecycle projection, point-in-time non-throwing provider input capture, and bounded replay-then-live subscriptions. Exact retry completes a retained submit/response/interrupt without repeating its provider call; this in-memory guarantee is not crash durability. Session closure becomes terminal only after provider disposal and workspace release both succeed; failed-open rollback cleanup remains visible to exact retry and shutdown. Unstarted subscriptions retain only a sequence high-water mark; event bodies remain in durable storage until replay begins, and late terminal subscribers close after replay.
