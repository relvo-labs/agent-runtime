# `@relvo-labs/agent-runtime`

Provider-neutral composition root with mutation-isolated in-memory storage, scoped command idempotency, retained failed-effect fingerprints, retryable cleanup-aware shutdown, exactly-once terminal settlement, fail-closed lifecycle projection, point-in-time provider event capture, and bounded replay-then-live subscriptions. Session closure becomes terminal only after provider disposal and workspace release both succeed; failed-open rollback cleanup remains visible to exact retry and shutdown. Unstarted subscriptions retain only a sequence high-water mark; event bodies remain in durable storage until replay begins, and late terminal subscribers close after replay.
