The scripted-demo provider never paces itself — nothing happens after Send turn until you click Advance script (its own public test controller), so a run genuinely stays in flight long enough to try Interrupt run for real. A real provider profile paces itself and this button will not appear for one.

Disconnecting only closes this page's own event stream — it never cancels the run itself. Reconnecting resumes from the last event this page actually saw, not from the beginning, and is not durable provider resume across a backend restart.
